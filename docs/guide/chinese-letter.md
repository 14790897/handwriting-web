# 中文书信排版

中文书信有固定的样子：称呼顶格、段首空两格、段间不留空行、落款和日期靠右。
手动排这些很烦，「书信排版」按钮一次做完。

## 怎么用

1. 先把信的正文写进文字框。
2. 点文字框上面的**「书信排版」**按钮。
3. 弹出的窗口里能看到排版预览。如果程序在正文末尾认出了署名和日期，会自动填进对应的框里。
4. 需要的话手动改「署名」和「日期」，两个都是可选的。
5. 点**「应用排版」**写回文字框。点「撤销排版」可以还原成排版之前的样子。

点「应用排版」之后文字框里的内容真的变了，之后仍然可以继续手动编辑。

## 它到底改了什么

| 动作 | 说明 |
|---|---|
| 去掉空行 | 正文里所有的空行都会删掉，段与段之间不再留空隙。 |
| 段首空两格 | 每行开头补上两个全角空格。 |
| 称呼顶格 | 如果第一行以 `：` 或 `:` 结尾（比如「尊敬的老师：」），这一行不空格。 |
| 落款靠右 | 署名和日期各自加上 `>>>`，渲染时靠右。 |
| 保留其他标记 | 已有的 `>>>` 保持靠右；`---` 分页标记原样保留。 |

!!! note "它按行处理"
    程序把**一行当成一段**。如果你的正文里一段话被硬换行拆成了好几行，
    那这几行都会各自空两格。想要严格的段首缩进，就先保证一个自然段写在一行里。

## 自动识别落款

「应用排版」之前，程序会先看正文的最后两行，试着把落款摘出来：

- **日期** —— 最后一行长得像日期就认定是日期，认得的写法包括
  `2026年7月26日`、`2026-07-26`、`2026/7/26`、`7月26日`、`二〇二六年七月二十六日` 等。
- **署名** —— 日期上面最多两行。2～4 个汉字、英文姓名、
  「爱你的…」「儿子/女儿/父亲/母亲…」这类称呼，或者以「敬上」「谨上」「谨启」结尾的，
  都算署名；以句号、感叹号、冒号等标点结尾的行不算。

识别对了就直接点「应用排版」；识别错了可以点「移回正文」把它放回去，或者自己手填。

## 举例

排版前：

```text
尊敬的老师：
　　您好！这学期多谢您的照顾。
　　此致
敬礼！
张三
2026年7月26日
```

选「书信排版」，程序认出「张三」是署名、「2026年7月26日」是日期，自动填好后应用，结果相当于：

```text
尊敬的老师：
　　您好！这学期多谢您的照顾。
　　此致
　　敬礼！
>>>张三
>>>2026年7月26日
```

落款那两行渲染出来就靠右了。想了解 `>>>` 本身，看[排版标记](layout-markers.md)。
