# 排版标记

正文里可以插入两种标记控制排版。它们只影响版面，**不会出现在生成的图片里**。

## `---` 强制分页

独占一行的三个或更多短横线，会让**接下来的内容从新的一页开始**。

- 行内的短横线不算，必须独占一行。
- 行首行尾多几个空格没关系。
- 三个、四个、更多都行。

```text
第一页的内容
---
第二页从这里开始
```

## `>>>` 靠右排版

放在**行首**的 `>>>` 会把这一行推到右边，署名和日期用这个最方便。
标记后面可以跟一个空格，这个空格会被吃掉，不算进正文。

```text
正文第一段。
正文第二段。
>>>张三
>>>2026年7月26日
```

`>>>` 只是**把整行推到右边**。要精确对齐署名和日期的起笔位置，
用[中文书信排版](chinese-letter.md)更省事。

## 两个一起用

```text
尊敬的老师：
　　您好！……
　　此致
敬礼！
>>>张三
>>>2026年7月26日
---
附：成绩单一份
```

这段会生成两页：第一页是信和落款，第二页是附件说明。

!!! tip "也可以让程序帮你插"
    手写 `>>>` 只是为了精确控制。绝大多数时候，
    直接点「书信排版」按钮让它自动把落款推到右边就够了。
