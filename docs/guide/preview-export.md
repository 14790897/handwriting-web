# 预览与导出

## 预览

点顶栏的**「预览手写图像」**，右栏会显示渲染结果。

- **预览只渲染第一页** —— 目的是让你快速看参数调得对不对，不用等整篇渲染完。
- 文字排到多页时，预览下方出现「上一页 / 下一页」和「第 x 页 / 共 y 页」。
- 改了任何参数，都要**重新点一次预览**才会更新，界面不会自动重渲染。

## 导出图片（zip）

点**「生成完整手写图片」**，后端把每一页渲染成 PNG，打包成 `images.zip` 下载。

- 压缩包里按顺序放着各页的 PNG 文件。
- 这是拿到全部页面最直接的方式，适合后面自己排版或者贴进别的文档。

## 导出 PDF

点**「生成pdf」**，后端把所有页面合并成一个 `images.pdf` 下载，不用再手动把图片粘进文档。

!!! tip "怎么选"
    要往 Word 里插图、或者想自己控制页面顺序 → 用 **zip**。
    想要一个能直接打印、直接发的文件 → 用 **PDF**。

## 页数与限制

- 文字区下方会显示**页数估算**，输入时就能看到大概要出多少页。
- 在 `handwrite.14790897.xyz` 上**单次最多渲染 10 页**，超出部分会被截断；
  估算提示和超限弹窗都会提前告诉你。自己部署的实例没有这个限制，但受
  [资源限制](../self-hosting/fonts-and-limits.md)影响。

## 排队、冷却与失败

- **冷却** —— 两次生成之间要等 3 秒，按钮上会显示倒计时。
- **排队** —— 后端同时只处理有限个任务。队列满了会弹出等待倒计时，告诉你大概还要多久。
- **进度** —— 生成中的状态通过 WebSocket 实时推送；WebSocket 连不上时自动退回轮询，
  界面上看不出区别。
- **失败** —— 如果后端渲染出错，任务会以失败结束并给出错误信息。
  自己部署的话，详细信息在容器日志里：

  ```shell
  docker compose logs backend
  ```
